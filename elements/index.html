Quick glossary

A few BigChange-specific terms used throughout this document.

Job Folder
The single record for a job — notes, worksheet, attachments, financials — all opened and edited on the same screen rather than in separate tabs.
Worksheet
A configurable digital job sheet: questions, photos, signatures, and "at risk" flags completed by the engineer against a job.
Resource
A field engineer (or vehicle) as represented in BigChange, with skills, groups and starting location.
Note Flag vs Job Flag
Two separate flag systems: Note Flags mark a follow-up's stage (e.g. "Awaiting Parts"); Job Flags mark a job's status on the schedule board.
Territory
A geographic area assigned to a resource or group, used to allocate jobs to the nearest suitable engineer.
Follow-On Job
A new job automatically created when a job result meets a condition — e.g. "parts required" spins up a parts-ordering job.
Network
BigChange's B2B layer for sharing jobs with subcontractors who are also on BigChange.
Lightning
BigChange's AI suite (Cooper AI brain), included as standard, bundling the AI agents described later in this document.
Dashboards Viewer
A per-user licence that controls who can open Business Intelligence dashboards.
User for Integration
A non-active-user account type used purely to hold API keys / run automations — doesn't consume a standard user licence.
